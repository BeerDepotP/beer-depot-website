Live link to KORONA
Mirrors KORONA into this POS about every 5 minutes: new products, stock, prices, names, barcodes, distributors and active status. It only reads from KORONA and never changes it. While this is on, KORONA is the boss, so edits made here are overwritten on the next check. Turn it off before you go live. In KORONA, create a user with read-only rights for the API and type its login below (never send it in chat).
