# The Beer Depot website — how we work

- Owner: The Beer Depot, Pewaukee WI. Domain: beerdepotpewaukee.com (bought through Netlify 2026-11-03). Hosted on Netlify (project "cute-salamander-50d302"), deployed from the `main` branch of this repo.
- **Every push to `main` is a Netlify production deploy and costs 15 credits.** The owner asked that changes be batched.
- Do all work on the `drafts` branch. Push `drafts` freely (it does not publish).
- Only merge `drafts` into `main` and push when the owner explicitly says to publish.
- Preview drafts without a deploy: run `python3 tools/build.py` and show `preview.html` (sample stock).
- Edit `tools/index.template.html`, then run `python3 tools/build.py` to regenerate `public/index.html`. Do not hand-edit `public/index.html`.
- Live stock comes from KORONA via `netlify/functions/stock.mjs`, which serves a saved copy from Blobs ("stock-latest") instantly and refreshes it in the background when over 60s old; `stock-refresh.mjs` also rebuilds it every 10 min, 6 AM–10 PM Central. Section rules live at the top of that file. Check sorting with `/api/stock?report=<REPORT_KEY>`.
- Store Tools at /food-stock (PIN in FOOD_PIN): tabs Food Stock (switches, Netlify Blobs; every item has an Edit button opening a drop-down for name, prices and picture: food-stock blob `edits[key]` {label, photo} + `prices[key]`, photos in Blobs "food-photo-<id>" served by GET /api/food-stock?photo=<id>, helpers menuLabel/menuPrices/menuPhoto at the bottom of tools/menu.js; pizza toppings list is editable (Add/Remove, blob `toppings`, no pictures); Add-Ons (gyro) and pellet flavors are not editable in the drop-down; jump buttons at the top for each food group, maker and Grilling & Outdoor), Sales (On Sale section at the top of the site + red On Sale chip; on/off switch, items with photo/name/sale price/regular price/note, "Save $X" computed; sales.mjs, Blobs "sales" + "sale-photo-<id>", photos shrunk in the browser), Seasonal (after Sales; on/off switch hides it completely; one editable name used for the menu-bar chip, Browse drawer and section heading; items with photo/name/price/note; seasonal.mjs, Blobs "seasonal" + "seasonal-photo-<id>"; section sits right after On Sale), Couldn't Find It, Top Searches, Requests (each row has an × to remove it: insights.mjs type "remove"; Top Searches deletes the term for that week, Couldn't Find It only clears its no-result count, Requests deletes the request), Bourbon Club, with unread badges. No deploy needed for switch changes. Menu data: tools/menu.js. Functions: food-stock.mjs, insights.mjs, shared PIN check in netlify/lib/pin.mjs.
- Hours: Store Tools tab Hours (normal weekly hours + One-Day Changes for a date: closed or short hours + note; past dates drop automatically so it reverts the day after). hours.mjs (GET /api/hours public, Blob "hours" {weekly,overrides}); website HOURS in the template is the default until /api/hours loads (weekly null = defaults), hoursFor(offset) merges overrides, notice bar #hours-note shows overrides within 14 days. JSON-LD hours in <head> stay static: update if weekly hours change.
- Back in Stock emails: every Out of Stock item (KORONA rows key "k:<name>", Made Here/Local cards "f:<switch name>", Outdoor items "o:Outdoor: <name>", only when the top switch is off) gets an "Email Me When Back" button (modal on the site). notify.mjs (/api/notify: public request + unsub, PIN actions list/settings/clear/removeEmail), notify-check.mjs every 10 min 6 AM-10 PM Central: emails once an item has stayed In Stock for the wait time (default 60 min, editable; resets if it goes out again). Blobs "notify" {wants,tokens} + "notify-state" {on,delayMin,inSince,sent}; helpers in netlify/lib/notify.mjs; sendMail() in club-email.mjs (Brevo). Store Tools tab "Back in Stock": on/off (off hides buttons and stops emails), wait time, who waits for what (with Remove/Clear), recently sent.
- Bourbon Club send day/time: settings blob fields day (0=Sun) + time "HH:MM" (default Thu 17:00), edited in Store Tools; bourbon-club-weekly.mjs runs every 15 min and sends within 75 min after that time.
- Layout (Store Tools tab "Layout"): the website buttons (top bar chips + Browse drawer, ALWAYS the same single list/order) can be moved (arrows), renamed, turned off, added (custom sections "c-xxxx", 21+ only unless "Show to Under 21 Too") and linked to KORONA commodity groups. Blob "layout" {items:[{id,name?,off?,custom?,open?,groups?}]}; layout.mjs (/api/layout: public GET without groups, PIN list/save/reset; save also rebuilds stock), netlify/lib/layout.mjs (built-in ids + cleanLayout; keep in step with STATIC_NAV/DEFAULT_SECTIONS in the template). stock.mjs groupLinks(): linked group name -> section id wins over the regex rules (tags still win over links; BLOCK/DO NOT USE still hidden). Template: layoutOrder/applyLayoutSections/applyOrder; #main is a flex column and #drinks is display:contents so every section gets CSS `order` from the button order (catering follows Made Here); last layout cached in localStorage "bd-layout". Seasonal button name comes from the Seasonal tab.
- Made Here menu editing (Store Tools → Food Stock): ▲▼ order per group, "+ Add an Item to <group>" (custom items name "c-xxxx", label/group/desc; prices/photo via the normal edit keys), Edit drop-down has Description (added items), On Special (special price per price row + optional end day/time in store time; turns itself off) and Remove From Website. Removed items list at the bottom ("Removed From the Website": Put Back, Delete Forever for added items). Stored in the food-stock blob: custom, order {group:[names]}, removed {name:true}, specials {name:{on,prices:[[label,price]],until}}; actions addItem/order/removeItem/restoreItem/deleteItem/special in food-stock.mjs (expired specials tidied on save). Helpers in tools/menu.js: setMenu, foodItems(group), allFood, isRemoved, specialOf. Website: items on special go to the FRONT of their own group (owner did not want a separate Specials group), red outline + "Special" flag, regular price crossed out, "Save $X". Specials are Made Here only. Local Favorites (same tab) also has ▲▼ order (order key "local:<maker>"), "+ Add an Item to <company>" (custom item with `maker`), Remove From Website, Edit Company (name + city: blob `makers[key]` {name, where}) and "+ Add a Company" (blob `newMakers` [{id:"m-xxxx",name,where}], Delete Company for added ones). Company key never changes when renamed. Helpers makerKeys/makerInfo/localItems in tools/menu.js. Added Grebe's items are not in the Thursday auto-restock list. Grilling & Outdoor (same tab): ▲▼ order (order key "outdoor"), "+ Add an Item to Grilling & Outdoor" (custom item with outdoor:true; switch/price/edit key "Outdoor: c-xxxx"), Remove From Website, and Edit Flavors (any item; blob `variants["Outdoor: <name>"]` = [{v, note}] replaces the built-in variants; notes show under the flavor on the site). Helpers outdoorItems/flavorsOf in menu.js. Removed list covers Made Here, Local Favorites and Outdoor; every removed item has Delete Forever (built-in items get blob `deleted[key]=true` and never show again; added items are erased). Store Tools uses its own Yes/Cancel pop-up askYes() instead of confirm() (confirm is blocked in the artifact demo).
- Banners & Text (Store Tools tab): Announcement Bar (on/off, text, link to a section/web page/call, color red/orange/dark, optional auto-off time), Hot Ham banner (on/off, day, from/until, wording with {until}; replaces the fixed HOT_HAM), Page Wording (hero heading, search hint, Made Here intro, catering heading/text/button). site.mjs (/api/site public GET + PIN list/save), Blob "site"; template applySite() (cached in localStorage "bd-site"), ids #announce #hero-title #made-intro #cat-title #cat-text #cat-btn #ham-text.
- Made Here groups: Store Tools "Edit Groups" (rename, reorder, add, note under the name, remove when empty); food-stock blob `groups` [{key,name,note}] (key never changes; new ones "g-xxxx"); items move groups via Edit → Group (edits[name].group). Helpers foodGroups()/groupOf() in menu.js; FOOD_GROUPS/FOOD_GROUP_NOTES are only the defaults.
- Sales and Seasonal have an optional "Turn Off By Itself On" time (blob field `until`, store time; GET treats it as off after that).
- Staff PINs: owner PIN = FOOD_PIN (Netlify) opens everything incl. the Staff tab (owner only). Staff are added in Store Tools → Staff (name, PIN 4–12 digits, which tabs, on/off, Change PIN, Remove); Blob "staff" {members:[{id,name,salt,hash,tabs,on}]}, PINs stored as salted sha256, nothing set in Netlify. netlify/lib/pin.mjs: pinUser(), checkPin(store, pin, area) where area = tab id (food/sales/seasonal/hours/notify/layout/banners/nofind/top/requests/club), "owner", an array, or empty; every function passes its area (insights badges = any PIN). staff.mjs (/api/staff whoami/list/add/update/remove). Store Tools hides tabs the PIN can't use and shows the name in the header. Change log: checkPin(store,pin,area,body[,logArea]) writes a plain-words line via netlify/lib/activity.mjs describe() to Blob "activity" [{at,who,staff,text}] (owner + staff, last 500); Staff tab shows each member's last change, a "Changes" list filterable by person, and See Their Changes.
- Grebe's auto-restock: grebes-restock.mjs sets every Grebe's switch to In Stock each Thursday 9 AM Central (list in netlify/lib/restock.json, generated by tools/build.py from menu.js).
- Sections drawer: 3-line menu button left of the logo (and left of the small search bar when scrolled) opens the "Browse" drawer from the left (ends with a Request an Item link to #request). On Sale section sits right after Made Here listing the same chips as the menu bar; tap jumps there. Menu bar highlights the current section (spy()), centered on phones, two balanced rows on computers.
- Hot Ham banner: default HOT_HAM in tools/index.template.html (Sunday 9 AM–3 PM); edited in Store Tools → Banners & Text. Home-screen icons in public/img + public/manifest.webmanifest.
- Grilling & Outdoor: fixed list OUTDOOR in tools/menu.js; In Stock unless switched off in Store Tools (switch key "Outdoor: <name>"); prices editable in Store Tools (food-stock blob `prices[key]`, overrides menu.js). Pellets have `variants` (flavors), each its own switch "Outdoor: <name> – <flavor>"; all flavors off = Out of Stock. Owner said 2026-11-03: do NOT add ice (KORONA group ICE stays off the site). Soda (Soda & Mixers → Soda) always shows In Stock, even without KORONA stock history (stock.mjs `alwaysIn`).
- THC section (KORONA group THC) after Seltzers, 21+ only, auto-hides from 2026-12-11 (federal hemp THC limit) via `until` in SECTIONS.
- KORONA tags override sections (TAG_SECTIONS / HIDE_TAGS in stock.mjs). Tag "Allocated Bourbon" -> Whiskey & Bourbon, shown in its own box on the right (top on phones).
- Food photos: JPGs in public/img/food (900x675, 4:3, ~80 quality), set `photo:"file.jpg"` in tools/menu.js; build.py inlines them into preview.html (FOOD_PHOTOS). Owner sends phone photos; correct lighting (sun stripes on the wood board) and crop 4:3 around the dish. Rotate so the wood grain runs side to side (owner wants all photos to match). Packaged products (Local Favorites, vacuum packs): keep package upright, crop 4:3 to the label + top of product, and remove plastic glare; Kraemer cheese blocks use the LIGHT touch only, owner preferred it (photowork kr.py LIGHT=True) (owner approved strong cleanup for vacuum packs 2026-11-04: inpaint white streaks on the product, darken streaks on black plastic toward black, never touch the label; leave the clear edge flap). Food: tame glare lightly only.
- Local Favorites makers: Northern Trails & Kraemer (Watertown), Pernat's (Ixonia), Sausage Haus (Oconomowoc), Grebe's (West Allis). Each flavor is its own card/switch; `name` is the unique switch key, `label` is what shows.
- Any KORONA group or product with "DO NOT USE" (or DNU) in its name is always skipped (RETIRED in stock.mjs). Owner retired groups this way, e.g. "DO NOT USE SODA", "DO NOT USE JUICE".
- Owner preferences: Title Case on names, labels and buttons ("Mac & Cheese", "Each", "In Stock"). Never show "Call to Check".

- FOOD_PIN is set in Netlify (owner PIN; staff PINs live in Blobs). Owner confirmed the address as written: "N27 W26 N26980 Prospect Ave, Pewaukee, WI 53072".
- Cloudflare Web Analytics token is in tools/build.py (live site only, not on Store Tools or the preview).
- Store info (ADDRESS, HOURS) is at the top of tools/index.template.html; the Google info (JSON-LD LiquorStore, hours, address) and sharing tags are in its <head> too, so update both if hours change. robots.txt hides /food-stock and /api; sitemap.xml lists the home page. New Arrivals: stock.mjs records each product's first in-stock date in Blobs (`first-stocked`); first run seeds everything as old.
